# 💧 Consumo de Água — Classificador de Perfil de Consumo

### 🎯 Sobre o projeto: Este projeto foi desenvolvido para a campanha de conscientização ambiental da companhia de saneamento da cidade. O objetivo é classificar o perfil de consumo de água dos imóveis (comercial, casa ou apartamento) a partir do consumo mensal informado (em m³) e emitir alertas educativos que incentivem o uso consciente e sustentável da água. 🌎💧 

### ⚙️ Como funciona:
🏠 O programa solicita o tipo de imóvel: comercial, casa ou apartamento.


🚰 Em seguida, solicita o consumo mensal de água em m³ (número decimal).


📊 Com base nas regras de negócio, exibe uma mensagem de classificação:
Situação	Mensagem exibida
🏢 Imóvel comercial	Tarifa comercial aplicada – consulte o plano corporativo.
🌱 apartamento com consumo menor que 10 m³	Consumo econômico – excelente controle de água!
🔵 apartamento (demais casos) ou casa com consumo até 25 m³	Consumo moderado – dentro do padrão residencial.


🚨 Demais casos (consumo acima do padrão residencial)	Consumo excessivo – adote medidas de economia e verifique vazamentos.

### Tecnologia utilizada: Python 


### ▶️ Como executar

Você pode rodar o app.py diretamente pelo seu editor/IDE favorito, sem digitar comandos no terminal:

### 🟦 Visual Studio Code
Baixe o repositório em Code → Download ZIP e extraia a pasta consumo-agua.
Abra o VS Code e vá em File → Open Folder..., selecionando a pasta consumo-agua.
Instale a extensão oficial Python (da Microsoft), caso ainda não tenha.
Abra o arquivo app.py.
Clique no botão ▶️ Run Python File no canto superior direito da tela.
Responda às perguntas no painel de terminal integrado que abrirá automaticamente.
### 🐍 IDLE (vem instalado junto com o Python)
Abra o programa IDLE no seu computador.
Vá em File → Open... e selecione o arquivo app.py.
Com o arquivo aberto, pressione F5 (ou vá em Run → Run Module).
Responda às perguntas na janela do Shell que será exibida.
